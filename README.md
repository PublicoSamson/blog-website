# DevNotes - Personal & Community Blog Website

## Site Description
DevNotes is a 3-page interactive blog web application built with HTML5, CSS3, and Vanilla JavaScript. Users can browse published articles on the Home page, publish new posts via the Write Post page, leave comments on any post (saved using browser localStorage), and learn more about the platform on the About page.

## API Used
- *DummyJSON Quotes API* (https://dummyjson.com/quotes/random): Used on the Home page to dynamically fetch and display random motivational quotes for readers.
