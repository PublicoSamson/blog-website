About DevNotes

DevNotes is an interactive community blog built with HTML, CSS, and Vanilla JavaScript. Visitors can publish articles, share ideas, and leave comments on any post.

Features

  • Create and publish new blog posts stored locally in your browser.
  • Interactive comment section under every post.
  • Live motivational quotes fetched dynamically using the DummyJSON Quotes Public API.
